<p><strong>Rating: 8/10</strong> · Played 3 times</p>
Fairly simple and a lot of fun. Although there is some downtime, it is not too noticeable. From an aesthetic point of view the game is beautiful and hilarious. The game is also reasonably low stress. The main shortcoming of the game in my opinion is the sort of menial end game scoring.
