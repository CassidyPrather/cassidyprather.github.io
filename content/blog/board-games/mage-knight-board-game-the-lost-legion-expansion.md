<p><strong>Rating: 9/10</strong></p>
This provides a very distinct victory condition to Mage Knight which changes the way the game needs to be approached to a moderate extent. It also provides several quality-of-life balancing changes, which are very pleasant, and a few more mechanics to break up the monotony of the original's limited tile supply.
