I never thought I would be so deeply invested in a "take that" game but this has done it. it has sold the flesh to me, the prophet of flesh.<br>
The game's scoring system is logarithmic which is... An issue. But it is otherwise mechanically elegant and promotes very engaging and creative player interactions.
