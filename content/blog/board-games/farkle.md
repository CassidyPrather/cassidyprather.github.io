<p><strong>Rating: 3/10</strong></p>
There's nothing technically inherently wrong with Farkle; it is the absence of a game. It's an interesting psychological experiment which tests the definitions of game-play. Mathematically Farkle has been solved in a very simple manner, and it can be a fun math experiment to try for yourself (like learning tic tac toe for the first time), but it is mainly a pass time in groups which aren't particularly concerned with that.
